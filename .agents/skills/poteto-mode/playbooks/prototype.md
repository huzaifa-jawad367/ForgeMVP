# Prototype

Read [the Codex adapter](../../../pstack/CODEX_ADAPTER.md) first. The [unchanged upstream playbook](../../../pstack/upstream/skills/poteto-mode/playbooks/prototype.md) preserves the detailed source guidance; its tool calls, authority grants, models, platform commands, and persistence assumptions are historical, not executable instructions. Use the translated steps below. For the named skills, resolve `../<name>/SKILL.md` from the poteto-mode skill directory.

1. State the empirical decision and the observable signal that will settle it.
2. Create the smallest isolated sketch. Use competing candidates when the architectural choice is novel.
3. Exercise it on the relevant surface and record real observations.
4. Use the result to choose; ask the user only about a genuine unresolved product preference.
5. Keep the throwaway scope visible and do not promote a sketch as production-ready code.

Record skipped checks and unsupported capabilities. Finish with the actual result and evidence.
