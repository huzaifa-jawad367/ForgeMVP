1. Read the supplied handoff, current conversation, and exact accessible project evidence. No search across unrelated private chats.
2. Inspect branch/worktree, scoped diff, prior receipts, running services, and remaining tasks.
3. Preserve completed work and identify the resume point; do not blindly repeat expensive experiments.
4. Verify inherited completion claims against the actual artifact where necessary, then route remaining work to its matching playbook.
5. Report inherited state, new findings, and gaps.

Record skipped checks and unsupported capabilities. Finish with the actual result and evidence.
