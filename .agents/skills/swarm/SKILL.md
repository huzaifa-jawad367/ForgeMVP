# Swarm

Partition work or compare attempts, drain all required results, and return one report.

1. State the done predicate, coverage slices, and output. For a race declare first-pass, rank-all, or best-of before launching.
2. Write self-contained briefs with scope, relevant paths, exact commits when measuring/reviewing, verification method, and required evidence. Default to model inheritance. Keep one writer per output or worktree.
3. Use available delegation calls, bounded by actual session capacity. Queue additional slices instead of promising an unlimited cloud fleet. If no delegate API is available, perform the slices sequentially and say so. Read-only is a brief restriction, not a tool-enforced sandbox.
4. Each result is PASS, ISSUES, or BLOCKED with evidence. Missing required identity or measurement method gets one targeted retry, then an explicit gap. A dropout never becomes a pass.
5. Inspect actual artifacts, aggregate coverage, and apply the declared race rule. Return one report with findings and gaps, rather than pasting worker transcripts.
